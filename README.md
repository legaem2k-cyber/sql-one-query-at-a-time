Practical Exercises: HealthConnect

I use healthcare appointment scenarios inspired by my HealthConnect data analytics project to practise SQL.

My exercises explore questions such as:

How many appointments fall into each outcome category?

How can appointments be filtered by previous no-shows?

How can results be grouped by appointment outcome?

How can I identify categories with more than a specified number of records?

How can I classify previous no-show counts into risk categories?

These exercises help me practise writing queries and understanding how SQL supports data analysis.

Note: Practice queries are learning exercises unless explicitly identified as results calculated from the actual dataset.
